# Application Icons

For production builds, you need to provide application icons in the following formats:

- icon.ico (Windows) - 256x256 pixels
- icon.icns (macOS) - 512x512 pixels  
- icon.png (Linux) - 512x512 pixels

You can use online tools to convert a single image to all formats:
- https://convertio.co/
- https://cloudconvert.com/

Recommended icon guidelines:
- Simple, recognizable design
- High contrast
- Works well at small sizes (16x16)
- Transparent background (PNG)
- Related to accounting/finance theme

For development, Electron will use a default icon if these files are missing.
